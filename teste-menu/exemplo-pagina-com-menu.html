Esta página usa o menu separado

🎯 Como Usar o Menu Separado

  1. Inclua o CSS do menu no <head>
  2. Inclua o HTML do menu antes do </body>
  3. Inclua o JavaScript do menu antes do </body>
  4. O menu será inicializado automaticamente

📋 Código para Incluir

<!-- No <head> -->
<link rel="stylesheet" href="/menu.css">

<!-- Antes do </body> -->
<script src="/menu.js"></script>
<div id="menu-container"></div>
<script>
    // Carregar o menu
    fetch('/menu-template.html')
        .then(response => response.text())
        .then(html => {
            document.getElementById('menu-container').innerHTML = html;
            // Inicializar o menu
            if (window.menuLateral) {
                window.menuLateral.inicializar();
            }
        });
</script>
