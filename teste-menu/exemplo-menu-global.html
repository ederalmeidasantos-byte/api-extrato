🌐 Menu Global Automático

Sistema que carrega o menu automaticamente em qualquer página

🎯 Como Funciona

🔍 Detecção Automática

Verifica se a página já tem menu. Se não tiver, carrega automaticamente.

⚡ Carregamento Dinâmico

Carrega o HTML e CSS do menu sem modificar o código da página.

🎨 Estilo Consistente

Mantém o mesmo visual em todas as páginas automaticamente.

📱 Responsivo

Adapta-se a diferentes tamanhos de tela automaticamente.

📋 Como Usar

Para usar o menu global em qualquer página, basta incluir este script:

<!-- Incluir antes do </body> --> <script src="/menu-global.js"></script>

Isso é tudo! O menu será carregado automaticamente.

✅ Vantagens

  • Zero configuração: Funciona em qualquer página
  • Não interfere: Se a página já tem menu, não faz nada
  • Manutenção fácil: Uma alteração afeta todas as páginas
  • Performance: Carrega apenas quando necessário
  • Compatível: Funciona com qualquer estrutura de página

🧪 Teste o Menu

Passe o mouse na lateral esquerda da tela para ver o menu em ação!
