🧪 Teste do Sistema Global

Esta página foi criada sem menu para testar o sistema global.

⚠️ Observação Importante

Se você está vendo um menu na lateral esquerda, significa que o sistema global funcionou! O menu foi carregado automaticamente.

🔍 Como Funciona

  1. O script menu-global.js verifica se existe um menu na página
  2. Se não existir, carrega automaticamente o menu padrão
  3. Se já existir, não interfere na página
  4. O menu fica disponível em todas as páginas automaticamente

📋 Código da Página

Esta página tem apenas o script global no final:
