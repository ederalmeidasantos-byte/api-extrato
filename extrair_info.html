📋 Informações

Descrição: Endpoint para extração de dados de extrato PDF

Método: POST

Status: ✅ Funcionando

⚠️ Importante

Este endpoint aceita apenas requisições POST com dados JSON.

Para usar via navegador, utilize ferramentas como Postman, Insomnia ou DevTools.

📝 Exemplo de Uso

POST /extrair HTTP/1.1 Host: inss.lunasdigital.com.br Content-Type: application/json { "fileId": "7539", "idoportunidade": "123" }
